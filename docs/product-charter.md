# Product charter

## Intent
Build a standards-based Web Components library for modern evergreen browsers. Public source is owned by The AI WC Factory (`The-AI-WC-Factory`) in `shell-web-components`, under MIT.

## Operating model
Humans own product goals, priorities, acceptance criteria, branding and general constraints. AI owns requirements refinement, architecture, design, implementation, testing, security, documentation, engineering review, packaging and release. Human account consent is not engineering review.

## Phase 0 boundary
Establish Issues, Projects, Git Flow, PRs, Actions, security and release governance. No components, framework selection, library architecture, demos or npm publication are in scope.

## Distribution and unresolved product details
npm is the release destination. `@ai-factored/shell-web-components` is the working package name, not an ownership claim. Verify npm scope control before configuring publication. Exact minimum browser versions, first features and compatibility/performance targets remain future product requirements.

## Completion
The bootstrap Issue's acceptance criteria must pass with deterministic evidence and independent AI review. Until then Phase 1 is blocked.
